## 🧠 My Learning Philosophy

For every major concept, I try to understand:

1. **What problem does it solve?**
2. **Why do we need it?**
3. **What is the mathematical intuition?**
4. **How does the algorithm work?**
5. **How is it implemented in Python / NumPy?**
6. **What happens to the data at each step?**
7. **What can go wrong?**
8. **When should I use it in a real project?**
